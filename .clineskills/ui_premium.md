# 💎 SKILL: UI Visual Premium (Dark Mode)

Esta habilidad asegura que la IA mantenga un estándar de diseño de altísima calidad.

## 🎨 PALETA DE COLORES (Dark Dashboard)
- **Fondo**: `bg-slate-950`
- **Tarjetas**: `bg-slate-900` con `border-slate-800`
- **Acentos**: 
  - Primario: `cyan-500` a `blue-600` (Gradients)
  - Éxito: `emerald-500`
  - Alerta: `amber-500`
  - Crítico: `rose-500`

## ✨ MICRO-INTERACCIONES
- Use `transition-all duration-300` en botones y tarjetas.
- Añada `hover:border-cyan-500/50` para dar feedback visual.
- Use `backdrop-blur-md` en modales y paneles flotantes.

## 📊 VISUALIZACIÓN DE DATOS
- Los Scores se muestran con **Gráficos Circulares (Radial Progress)**.
- Los Gaps de precio se muestran con flechas de tendencia (`TrendingUp`, `TrendingDown`).
- Use iconos de `lucide-react` para cada métrica (DollarSign para precio, Camera para fotos).
